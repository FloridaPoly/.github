# Reporting a security vulnerability

Do not open a public issue for a suspected vulnerability.

## How to report

Use GitHub private vulnerability reporting on the affected repository:

1. Open the repository on GitHub.
2. Go to the **Security** tab.
3. Choose **Report a vulnerability**.

Only people with access to that repository can see the report. If the Security
tab does not offer private reporting, or you are not sure which repository is
affected, email the Florida Poly ITS security contact instead and say that the
report concerns a GitHub repository.

## What to include

- What the issue is, and the impact if it were exploited
- The repository, and the affected version, branch, or deployed environment
- The smallest set of steps that demonstrates it
- Whether any real student, employee, or financial data is exposed

Do not include working exploit code in the initial report.

## What happens next

A maintainer acknowledges the report, confirms or rejects it, and agrees a fix
and disclosure timeline with you. Reports touching education records are handled
under the same FERPA posture as any other student-data incident.

## Scope

This applies to every repository in the FloridaPoly organization. A repository
that publishes its own SECURITY.md overrides this file.
